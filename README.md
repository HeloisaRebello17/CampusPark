# Campus Park
Trabalho destinado ao Projeto de Aprendizagem Colaborativa Extensionista VI - Sistema de Estacionamento | Campus Park

## Como rodar

Com o [Docker Desktop](https://www.docker.com/products/docker-desktop/) aberto, na pasta raiz do repositório:

```powershell
docker compose up --build
```

Depois abra http://localhost:8000.

Passo a passo completo (instalações, banco de dados, primeiro acesso, reconhecimento facial e
problemas comuns): **[COMO_RODAR.md](COMO_RODAR.md)**.

Instalação manual, sem Docker: `campuspark/CampusPark_Guia_de_Instalacao.md`.
